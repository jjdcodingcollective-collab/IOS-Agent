# Project Context

These files are curated local notes for Project Knowledge. The knowledge graph and vector store are the source of truth for durable records; these files are readable projections with references back to knowledge and source IDs when available.

- ACTIVE.md: short current-state summary.
- OPEN_QUESTIONS.md: unresolved questions to consider when relevant.
- CONFLICTS.md: active conflicting claims or assumptions to consider when relevant.
- PROJECT_STORY.md: narrative project background.
- DECISIONS.md: durable decisions.
- SOPs.md: standard operating procedures.
- REFERENCES.md: stable reference pointers and source notes.
- sessions/: curator-managed session summaries.
- sources/: curator-managed source summaries.
- .meta/: curator bookkeeping.
